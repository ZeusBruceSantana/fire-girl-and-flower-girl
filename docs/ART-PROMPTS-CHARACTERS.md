# Image prompts: every character still to paint

**For:** the owner · **Date:** 2026-10-31 · Matched to the style of the three princess paintings (soft coloured
pencil and gouache, warm light, three-quarter view facing right). 26 characters, then the princesses' extra poses.

## How to make each one

1. In the image tool, attach **Fire Girl's painting** (`art/heroes/fire/full.png`) as the style reference.
2. Paste the **Character Style Lock** once at the start of the chat, then one character prompt at a time.
3. Ask for a **transparent PNG**. If the tool cannot, ask for a plain white background and say so when you upload:
   I remove it (as I did for Electric Girl).
4. Upload to `art/incoming/` on GitHub in batches of five, any file names. I check each one, place it, and show you.

**Character Style Lock** (paste first):

```
Children's storybook character illustration in soft coloured pencil and gouache with visible pencil texture, warm golden light and gentle shading, the same style as the attached reference picture. Full body from head to feet, standing in a relaxed three-quarter view facing to the right, feet visible at the bottom of the picture, friendly open expression, soft rounded shapes, a clean readable silhouette. Transparent background. No text, no watermark, no ground or shadow under the feet, no other characters.
```

## The princesses' extra poses (for movement) · `art/heroes/<kind>/<pose>.png`

The game moves each princess's painting already (see the walking and breathing). A few extra poses make the walk
and the spells read as real movement. For each girl, attach **her own painting** as the reference and paste:

```

```
then add one pose at a time:

| File | Pose to add |
|---|---|
| `walk-1.png` | walking, left foot forward mid-stride, arms swinging gently |
| `walk-2.png` | walking, right foot forward mid-stride, arms swinging gently |
| `cast.png` | casting a spell, the magic hand raised high with her magic glowing brightly |
| `cheer.png` | jumping with joy, both arms up, big smile |
| `sleep.png` | asleep standing up, eyes closed, head tilted, a sleepy smile |

The two walk poses matter most: the game swaps them while she walks.
